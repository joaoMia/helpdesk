# Checklist de entrega — HelpDesk no Codex

- [ ] Tarefa e autorização identificadas; objetivo e critérios de aceite atendidos ou limitações declaradas.
- [ ] Diretório real confirmado como `C:\dev\helpdesk`; nenhum projeto irmão ou configuração de sistema alterado.
- [ ] Branch e pré-condições respeitadas; trabalho anterior preservado.
- [ ] Somente arquivos e operações do escopo autorizado foram incluídos.
- [ ] Requisitos e decisões aprovadas respeitados; propostas pendentes não viraram regras.
- [ ] Compatibilidade com as instruções compartilhadas do Claude mantida, sem alterações nelas fora do escopo.
- [ ] Referências e caminhos novos conferidos; nenhum segredo ou dado sensível exposto.
- [ ] Testes e verificações aplicáveis executados; falhas e itens não executados informados com motivo.
- [ ] Diff, staging e arquivos novos revisados; estado final do Git conferido.
- [ ] Commits, exclusões, merges e publicações somente quando explicitamente autorizados; mensagens em português identificam a tarefa e não acrescentam coautoria da IA sem solicitação.
- [ ] Relatório contém resultado, arquivos, comandos, validações, limitações, riscos e pendências para aprovação.
- [ ] Próxima tarefa não iniciada automaticamente.
